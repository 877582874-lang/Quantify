# 记忆库（Memory Library）

建立：2026-11-25，由 Cl 定立，Muse 落地。

## 用途

本目录是跨会话、跨 AI 的**持久记忆**。任何 AI（Muse、ChatGPT/Codex、Claude Code，或未来的工具）在上下文丢失、会话过长被压缩、或接手新任务时，**先读本目录**即可重建对 Cl、服务器、项目与规则的完整认知，不必依赖聊天记录。

## 常设规则（2026-11-25 Cl 定立）

1. **主动入库**：Muse 在工作中确立的持久事实（决定、基础设施事实、经验教训、状态变化），应**主动**写入本库，不等 Cl 开口。写完后在聊天里给一句短讯（改了什么、为什么、提交哈希），正文不进聊天。
2. **谁写谁署名（硬性，2026-11-25 10:01 Cl 再次明确）**：记忆库的**每一条记录**（不只是每个文件）都必须在条目末尾标注维护者署名与日期，格式如「—— Muse，2026-11-25」；无署名的记录视为无效记录，不得作为依据引用。更正旧记录时保留更正痕迹，不静默改写历史结论。
3. **只记经核实的事实**：数字、状态、结论须有当时的验证证据；推测与未确认事项必须显式标注「未确认」。
4. **禁存清单**：私钥、令牌、订阅链接、.env 内容、口令、行情数据本体、交易账户信息——一律不得写入本库。密钥只记**指纹与用途**，不记本体。
