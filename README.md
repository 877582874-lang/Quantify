## 留档规则（2026-11-24 由 Cl 定立）

1. 从本日起，量化系统（Crypto Quant Research Platform）的**任何更动、版本更迭，都必须在本仓库留档**：代码快照更新 + CHANGELOG 记录 + 阶段报告归档，三者齐全才算留档完成。
2. 只存代码、文档、报告与元数据。**不存**：行情数据本体（Raw/DuckDB/Parquet）、任何密钥/口令/.env 内容、交易账户信息。
3. 每个阶段的报告以当日实际交付版本为准，原始数字不改写；错误与事故如实记录，不美化。
4. 报告格式：单份 txt 汇总为默认（2026-11-24 Cl 定），历史 md 报告按原样保留。
